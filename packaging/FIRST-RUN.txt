拾序 1.0.0（Windows 10/11 x64）

从开始菜单或桌面打开「拾序」。第一次启动不包含原开发目录中的消息、待办、API Key 或登录状态。

运行要求
- Windows 10/11 x64；需要 Microsoft Edge WebView2 Runtime 与 .NET Framework 4.8。
- 已内置 Python 3.12 与程序依赖，无需自行安装 Python。
- 程序仅在本机 127.0.0.1:8000 提供服务。开发版和安装版不能同时占用该端口；请先从原程序托盘完整退出。
- WebView2 缺失时，可从微软官方网站安装 Evergreen Runtime：https://developer.microsoft.com/microsoft-edge/webview2/

消息与模型
- 手动导入、人工整理和待办管理可独立使用。
- 已内置 NapCat v4.18.38，无需单独安装 NapCat。仍需从 https://im.qq.com 安装官方 Windows QQ；本包不包含 QQ 客户端。打开“登录 QQ → 启动并登录”，由本人扫码或授权。
- 首次使用自动创建本机独立管理 Token；保存 QQ 账号、群号和接收 Token 后，内置组件会自动配置拾序上报。原有自行安装的 NapCat 优先使用，仍保留手动配置方式。
- 内置 NapCat 按其许可证仅限非商业用途，完整许可及来源位于 third_party/napcat/v4.18.38/LICENSE 和 SOURCE.txt。
- 微信接收需要本人电脑微信登录，在设置中填写微信号及群名后主动开启。兼容性依赖微信版本和当前账号权限。
- 模型分析需要配置 LM Studio 本地模型或本人 DeepSeek / OpenAI API，不包含模型权重与云端额度。
- 云端模型仅在用户主动分析时发送本次消息，请核对服务来源。

数据与退出
- 用户数据、配置及运行日志保存在当前安装目录的 data、runtime 与 *.local.json 中。
- 本安装包使用当前用户目录，无需管理员权限。
- 关闭窗口仅收起到托盘；通过托盘「退出拾序」完整退出。QQ / 微信客户端不随应用退出。
- 更新及卸载前请先在应用内退出 NapCat，再完整退出应用。卸载默认保留消息、待办、配置和自行安装的 NapCat。
- 升级前建议备份上述数据；本版本不自动迁移开发目录的数据。

本版本未进行跨电脑、长期稳定运行、注销/关机及所有 QQ / 微信版本的真实接收验证。
安装包未购买代码签名证书，Windows 可能显示「未知发布者」；请仅使用可信来源的文件并核对 SHA256。

微信新增消息分片会从该分片起点补收，原分片读取位置保留；可能包含此前未收取的消息。分片缺失或编号回退仍会停止。采集异常时可运行安装目录 DiagnoseWeChat.cmd，生成不包含聊天、账号或凭证的诊断报告。

本版保存正常启动失败阶段和脱敏系统错误码。若启动失败，先运行 DiagnoseQQ.cmd 提供 qq-diagnostic.json，不要先运行 StartQQ.cmd 改变现场。请保留故障现场以便排查。

覆盖升级使用新安装包自带的只读检查，不执行旧版检查代码。检查码10表示检测到后台运行，20表示无法完成检查；检查失败不代表后台必然运行。安装日志自动保存在系统临时目录。

安装完成后请先关闭安装器，再从桌面或开始菜单打开拾序。安装器不直接启动应用，避免其路径访问限制影响 NapCat 跨盘映射。

QQ 登录面板在等待扫码、初始化和状态异常时也提供“退出 NapCat”。旧版找不到按钮时，请先从托盘完整退出拾序，再运行 ExitQQ.cmd，输入 EXIT 确认并等待退出成功，然后卸载或升级。工具复用本安装目录的退出逻辑，不删除数据。

设置与连接新增“接收过滤”，默认关闭。开启后，将新收到的 QQ、微信短应答（如“收到”“好的”“谢谢”）移入垃圾桶，可恢复；不调用模型，不影响历史消息和手动导入。通知、问句及不确定内容保留；本规则不能识别所有闲聊。
