# 拾序 1.0.0

多源消息驱动的智能待办管理助手，支持 Windows 10/11 x64。首个正式编号版本，以 0.5.0-preview.10 为功能基线，本轮不新增业务功能。

## 主要功能

- QQ、微信文本消息及手动导入，统一收件箱。
- 本地或官方云端文本模型分析，草稿经人工核对后创建待办。
- 任务编辑、完成、恢复、通知变更追溯及疑似重复核对。
- 可恢复垃圾桶和默认关闭的短应答接收过滤。
- 内置 NapCat、换号自动配置、退出与脱敏诊断、桌面托盘。

## 下载与安装

下载 Shixu-1.0.0-win-x64-Setup.exe；Source code 是源码，不能直接当安装包运行。SHA256 见同一 Release 附件中的 SHA256SUMS.txt。安装完成关闭安装器，再从桌面或开始菜单打开。升级前退出 NapCat 和拾序，备份数据并选择原目录覆盖。

需要 WebView2 与 .NET Framework 4.8；QQ、微信、模型和 API 额度由用户自行配置。源码不含用户数据、凭证、第三方聊天客户端或模型权重。

## 边界

微信依赖本机已登录客户端的只读数据库适配；QQ 依赖第三方 NapCat，均受版本、权限和账号策略影响。图片及文件分析尚未实现。模型结果需人工核对。安装包未签名。含 NapCat 的分发受其非商业用途许可限制。正式编号不表示所有电脑及客户端版本都经过验证。
