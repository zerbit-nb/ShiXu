# 拾序 1.1.0

2026-10-27，Windows 10/11 x64。安装文件为 Shixu-1.1.0-win-x64-Setup.exe。

## 更新内容

- 精简设置页说明与按钮，移除侧栏底部说明，设置与连接及消息状态区下移；保留云端费用与数据发送提示。

- 可开关自动整理待办，默认关闭，本地模型需单独许可。明确通知自动创建，不确定内容留在消息收件箱；AI 结果仍需核对。云端会发送新消息文本并可能产生费用。
- 前台合并提醒支持多任务滚动查看；自动整理临时分组、详情高亮及定位、圆形平滑回顶。

## 安装与升级

内置 Python 和固定 NapCat v4.18.38，QQ、微信和模型需自行准备。需要 WebView2 Runtime 和 .NET Framework 4.8。可选择安装目录；完成后关闭安装器，从桌面或开始菜单打开。

从 1.0 升级前先在旧版 QQ 面板退出 NapCat，再从托盘退出拾序；备份 data、runtime 及 *.local.json，选择原目录覆盖。以后使用 1.1.0 托盘完整退出即可。安装器保留运行检查，不强制杀进程。
