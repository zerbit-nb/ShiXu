# 拾序 1.2.0

这一版围绕“接收更方便，任务更好找，重要事项及时提醒”升级，保留现有消息、待办和连接配置。

## 新功能

- **多群选择**：QQ、微信可读取并搜索群聊，勾选后以胶囊标签展示，支持移除与批量保存。微信最多选择 20 个群，QQ 最多 100 个；QQ 保留按群号填写入口。
- **微信号回填**：保存的微信号在当前 Windows 用户下加密存储，再次打开采集设置时自动回填。旧版只有摘要的配置需补填一次。
- **启动补收**：开启后，下次启动核对已选群当天零点至来源就绪时可读的文本，与实时接收去重。自动整理关闭时保留收件箱；开启时沿用既有模型和核对规则。疑似重复、改期、取消及未完成批次留待人工核对。
- **待办提醒**：支持提前提醒、每日回顾、静音时段、单项任务设置和稍后提醒。前台显示合并卡片，桌面托盘期间使用 Windows 通知，不调用模型。

## 界面与交互

- 待办中心调整分组列表、标题层级、工具栏、留白和当前任务选中反馈。
- 设置与连接统一排版、按钮、开关回弹和状态文字切换；重要说明可展开查看。
- QQ、微信接收面板统一搜索、多选及滚动体验，细滚动条用于各主要页面。
- 本地自动整理在主开关关闭时同步关闭并禁用；主开关重新打开后需单独允许本地模型。
- 已完成页的“管理”按钮位于搜索框与刷新按钮之间，保留批量恢复、删除和清空。
- 修复编辑待办后关闭详情的焦点返回，遵循系统减少动态效果设置。

## 安装与升级

下载 **Shixu-1.2.0-win-x64-Setup.exe**，支持 Windows 10/11 x64，内置 Python 与 NapCat v4.18.38。官方 QQ、微信、WebView2 Runtime 和 .NET Framework 4.8 仍按需由用户安装。

1. 从托盘完整退出拾序并等待清理完成。1.0 等旧版先在应用中退出 NapCat，再退出拾序。
2. 停止运行后备份原安装目录的 `data`、`runtime` 和 `*.local.json`；备份包含个人数据，请勿上传 GitHub。
3. 选择原安装目录覆盖安装。安装结束关闭安装器，从桌面或开始菜单启动。
4. 核对原有待办和连接范围，再按需开启“启动补收”和“待办提醒”；两项默认关闭。

完整退出会停止采集、自动整理、补收和提醒，并清理本安装关联的 NapCat。关闭窗口收起至托盘时继续运行。

## 使用范围与许可

当天补收依赖本机来源可读记录；微信版本、账号权限及 QQ 登录状态影响可用性。提醒在应用运行时工作，Windows 通知受系统设置影响。图片和文件分析、手机端及关机提醒尚未提供。云端自动整理会发送消息文本并可能产生费用。

原创源代码及随附文档采用 Apache-2.0；内置 NapCat 继续遵循其有限再分发许可和非商业用途限制。安装包附带完整第三方许可。安装包未签名，随附 SHA256 用于核对下载文件。

具体操作见 [使用与有效测试](usage-v1.md)，构建方式见 [安装包构建](../packaging/README.md)。
