# 拾序 1.2.0 使用与有效测试

## 环境与安装

Windows 10/11 x64，Microsoft Edge WebView2 Runtime、.NET Framework 4.8。应用使用本机 8000 端口；请先完整退出其他拾序实例。安装器内置解释器及 NapCat，官方 QQ、微信需分别安装。没有聊天客户端也能手动导入并管理待办。云端 API 需联网与用户自己的额度；本地模型需另行安装 LM Studio 并按模型要求准备内存和算力，拾序不包含模型权重。

下载 Release 的 Setup.exe 并核对 SHA256，选择可写安装路径。完成后关闭安装器，从桌面或开始菜单打开。未签名不等于已确认安全；仅使用可信来源的文件。

## 首次使用

1. 先用手动导入验证基本流程。在新建菜单输入一条测试通知，选择手动整理，填写标题和期限，核对后创建待办。
2. 设置与连接中配置模型。LM Studio 启用本地服务器、加载模型，检测后选择实际模型 ID；DeepSeek/OpenAI 填写官方 API Key 并检测模型。密码和令牌不用发给维护者。
3. QQ：打开登录面板，启动后台，由本人扫码、快速登录或账号密码授权。可用方式受 NapCat/QQ 状态影响。在接收设置中读取群聊，搜索并勾选目标群后保存，最多 100 个；也可展开“按群号填写”。登录后自动同步账号及上报配置，换号后核对接收范围。
4. 微信：本人登录电脑微信，在采集设置填写当前微信号，点击读取群聊，搜索并勾选目标群，最多 20 个。保存后主动开始采集。微信号在当前 Windows 用户下加密保存，下次打开回填；老配置需补填一次。异常时查看具体原因。重名群按标识区分；新选群默认从当前位置接收，历史文本另由启动补收处理。
5. 消息进入收件箱后再主动分析或手动整理，核对草稿后创建任务。完成、恢复、原文和历史操作均在应用中进行。
6. 接收过滤默认关闭，开启后仅将完整短应答移入可恢复垃圾桶。图片和附件暂不支持分析。
7. 设置与连接中可开启自动整理待办，默认关闭。明确通知自动创建，不确定内容留在收件箱；本地模型需额外许可。云端自动整理会发送新消息文本并可能产生费用。托盘期间继续处理，恢复前台后显示合并提醒，结果仍需核对。
8. “启动补收”默认关闭。开启后下次启动生效，核对已选群当天零点至来源就绪时可取得的文本。与实时接收去重，自动整理关闭时留在收件箱；开启时沿用现有模型。改期、取消及部分补收批次保留人工核对，不自动修改旧任务。补收不保证覆盖全部聊天记录。
9. “待办提醒”默认关闭。开启后默认提前 60 分钟提醒，可修改提前量、每日回顾和静音时段；时间按北京时间设置。仅日期的任务由每日回顾提示，无日期任务不自动定时提醒。详情可单独关闭或调整提醒；“稍后”不改变任务截止时间。前台显示卡片，桌面托盘期间使用系统通知；完整退出后停止。

本地自动整理仅在自动整理主开关开启时可用。关闭主开关会同时清除本地许可，再次打开后需重新允许。本机提醒不调用模型；云端自动整理处理新消息和符合条件的补收消息时可能产生费用。

## 最小有效测试

- 手动通知：输入“测试通知：请于2030年11月2日18:00前核对演示清单。”，手动核对并创建，检查日期、编辑、完成和恢复；此步骤无需模型。
- 模型分析：配置后主动分析一条虚构通知，检查草稿与原文对应；不要把模型输出当作已经验证正确。
- QQ/微信：只在获准测试的群中各发送一条不同文本标记，检查来源、正文和是否重复。不要在无关群刷屏。实际现场测试与替身测试分别记录。
- 过滤：在测试群发送一条“收到”，分别验证开关关闭/开启；开启后应在垃圾桶找到并可恢复。不要为测试大量发送消息。
- 多群选择：读取群列表，选择两个获准测试的群并保存；重新打开确认标签仍在。移除一个群后保存，核对接收范围；不保存的更改不生效。
- 启动补收：在获准测试的群中留下当天的一条标记，关闭自动整理、开启补收并完整退出，再重新启动和完成来源登录。查看补收状态及收件箱，核对正文、来源和重复情况。只有来源可取得的记录能补收，失败时查看状态，无需大量发消息。
- 提醒：开启待办提醒，测试时暂时关闭每日回顾。手动创建截止于当前时间 30 分钟后的待办，在默认提前 60 分钟设置下应很快显示卡片。点击稍后，确认截止时间未变；另建一条任务，在托盘期间测试系统通知。Windows 需允许通知，测试结束后删除测试任务或关闭提醒。
- 退出与保存：从托盘选择“退出 拾序”并等待完成；重新打开，检查待办和设置仍在。完整退出只清理关联进程，保留登录配置；QQ 能否恢复取决于原有授权。在 QQ 面板主动退出 NapCat 则维持原有暂停策略。

## 退出、升级与排错

窗口关闭会收起至托盘并继续接收和整理。升级或卸载前从托盘选择“退出 拾序”并等待完成；1.0 等旧版需先在应用内退出 NapCat。备份安装目录的 data、runtime、*.local.json。覆盖安装选原目录，无需先删数据。旧版没有退出入口时，托盘退出后运行 ExitQQ.cmd，输入 EXIT 确认。

QQ 异常可运行 DiagnoseQQ.cmd，微信异常可运行 DiagnoseWeChat.cmd。提供版本和脱敏错误码；分享任何报告前再次检查，不要附带聊天、登录二维码、Token 或 API Key。不要强制结束所有 QQ 进程、关闭防护或删除数据库。
